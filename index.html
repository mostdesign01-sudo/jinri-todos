做成桌面小应用

网页自己不能一直压在所有软件上面，要开成独立小窗，再用系统钉住。

  1. Chrome / Edge 最快：点「打开悬浮窗」。画中画小窗可以拖到桌面角落，会浮在别的窗口上。
  2. 做成真正的应用窗（没有地址栏）：用 Chrome 或 Edge 在开始菜单运行下面这一行（复制即可）。
  3. Windows 要一直置顶：安装 PowerToys，点一下小窗，按 Ctrl + Win + T。
  4. Mac：Chrome 菜单「将今日待办安装为应用」，打开后再用「打开悬浮窗」；或终端运行同一条 --app 命令。
