# 装到 iPhone

不需要 Xcode，也不需要苹果开发者账号。

1. 用 Safari 打开 https://mostdesign01-sudo.github.io/jinri-todos/
2. 底部分享 → 添加到主屏幕
3. 回主屏幕点「今日待办」

装好后是独立窗口：没有 Safari 地址栏，图标是勾选标记，数据在这台手机里。

## 和 App Store 的差别

| | 主屏幕应用（现在就能用） | App Store 原生应用 |
| --- | --- | --- |
| 要不要花钱 | 不用 | 苹果开发者账号，每年约 99 美元 |
| 要不要 Mac / Xcode | 不用 | 要 |
| 推送通知、小组件 | 有限 | 可以做 |
| 和网页同一份数据 | 同一台手机的 Safari 里是同一份 | 默认另一份，除非再做同步 |

上架需要另开一轮：用 Capacitor 或 WKWebView 包一层，再提交审核。需要的话再说。
